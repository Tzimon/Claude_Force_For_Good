**Title:** Show licenses link only next to the current version in release notes

---

### Short description
The "Licenses of used software" link in the release notes was shown next to the newest version of every year. It's now only shown next to the currently installed version.

### Proposed changes
- `release_notes/release_notes.html`: `forloop.first` referred to the inner loop over the versions of one year, so it was true once per year. The template now compares each version with the installed version from the `version` context processor. That global `version` variable is hidden by the loop variable of the same name, so it's first stored as `current_version` with `{% with %}`.
- Add two view tests: with an SBOM there is exactly one link, and it's next to `integreat_cms.__version__`; without an SBOM there's no link.
- Add a release note.

### Side effects
- In development, where the installed version may not match any release notes directory, no link is shown. That seems correct, since the SBOM belongs to the installed version.

### Faithfulness to issue description and design
There are no intended deviations from the issue and design. This follows the issue's suggestion to "pick the version the software reports as current".

### How to test
- `pytest tests/cms/views/release_notes`: 2 tests pass. On the old template, the first test fails with 5 links instead of 1.
- Manually: create `_manifest/spdx_2.2/manifest.spdx.json`, open `/release-notes/`, and check that only the current version has the link.
- djlint, ruff and mypy pass for the changed files.
